# V4/V8 由运行器管理终止交接

2026-10-06：V4/V8 对所有监督模型使用 `astra/TAKEOVER_V4_V8.md`。模型输入不包含自主 hand_back 协议、astra_pause_handback 配置或“暂停即可交还WAM”的提示；共享提示生成器保留真实观测、完整轨迹、工具和版本候选规则。运行器日志与请求原件仍保存配置供审计，只有模型输入副本移除该内部开关。旧版本协议保留。

模型应持续独立规划、执行版本允许的动作、根据反馈调整，必要时 observe；无法继续则如实 pause，硬件故障标记 hardware_fault；真正完成整个任务才 complete。V4/V8 的显式模型 hand_back 决策被拒绝。

启用现有 `--astra-pause-handback` 时，运行器在非硬件 pause（包括未分类停止）、监督调用最终异常、无效最终决策、审阅超时或 SSH 恢复窗口/次数耗尽后，使用同一代码路径进行兜底。HTTPS 内部重试、短暂 SSH 重连和 observe 不触发终止交接。

交接先检查硬件，清除队列、候选与待处理请求，保留 L2 和已消耗预算，下一轮基于新观测执行全新 WAM 推理；不重放旧动作、不复位、不宣称恢复成功。模型报告的 hardware_fault 或硬件检查失败会锁住本会话的自动兜底，仍可由操作者按既有流程处理；不会自动解除故障。人工取消、待处理的 T/B/P、正常 complete、WAM 自身错误和整个 runner 的退出不触发该兜底。关闭该开关保持暂停。

代码更新不热替换当前 runner/桥接。新的运行器和监督会话才能完整生效；旧会话历史仍包含旧提示，因此不能只修改提示文件就宣称当前实验已应用新策略。此次更新不自动恢复暂停的测试。
