# V10 子会话图片压缩

`astra/v10_images.py` 仅在 V10 组装模型附件时压缩图片；Astra 和 QuickRouter 子会话共用此入口。

长边上限 960 像素，保持比例，不放大；PNG 转成质量 85 的 JPEG。当前 1280×720 相机图发送为 960×540。小于上限的已有 JPEG 原样发送，所以 480×360 的示范帧不重复压缩。

当前观测、上一批动作的五个采样时刻（三视角共最多 15 张），以及进入最近两轮历史的观测图，均使用压缩后的模型附件。标签、顺序、动作行、时间戳与数量保持不变。原始 PNG、录像和 SSH 缓存不修改；V4/V8 的图片编码也不变。

压缩在 Windows 桥接端组装请求时完成，主要减少模型 API 请求大小，不减少 Leo3 到 Windows 的 SSH 原图传输。日志中的 model_input.json 保存实际发送的压缩图片。已运行的桥接需重启才能加载此修改。
