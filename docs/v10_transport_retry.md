# V10 Astra 传输重试

`astra/data_only_relay.py` 对 IncompleteRead、连接重置/RemoteDisconnected、TLS 意外 EOF、网络超时及 HTTP 408/429/500/502/503/504 自动重新请求，最多 3 次（首次加 2 次重试），间隔 2 秒、4 秒。

每次重新发送同一份固定输入，丢弃失败请求的部分回复。完整回复通过原有校验后才释放给上层；成功回复缓存，CLI 重复读取不会再次请求模型。重试期间不提交错误 decision、不自动交还 WAM；全部失败后保留现有代码兜底。

单次网络等待上限仍为 300 秒，所有尝试共享原有监督总超时（为外层退出预留 10 秒）。T/B、请求失效或桥接关闭后不会再发起重试或交付旧响应。已阻塞的网络读可能到超时才退出，但过期结果不会执行。

动作格式、工具调用、安全校验失败及鉴权错误不属于网络重试。日志记录 TRANSPORT RETRY、TRANSPORT RECOVERED 和 request ID，不记录鉴权信息。本功能只修改 V10 原生 Astra 的传输，不改变其他版本或 QuickRouter 路径。

需重启 Windows 桥接才能加载代码；不会自动重启正在运行的测试。
